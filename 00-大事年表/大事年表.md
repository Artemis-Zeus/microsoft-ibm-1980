## 一、前史（1942–1979）

| 时间 | 事件 | 引证 |
| --- | --- | --- |
| 1942-05-19 | Gary Kildall 生于西雅图。【WikiKildall】 | ★☆ |
| 1956-06-01 | Tim Paterson 生于西雅图。【WikiPaterson】 | ☆ |
| 1969 | 美国司法部对 IBM 提起反垄断诉讼（后历时 13 年，1982 年被撤销）；同年 IBM 实行「解绑」（unbundling），软件与服务单独计价——催生独立软件业。此案构成 IBM 在 PC 上不独占软件的制度背景。【WikiHistIBM】 | ☆ |
| 1973–1974 | Kildall 为 Intel 8080 写出 PL/M 语言；与 John Torode 合作做磁盘控制器并写出 CP/M，1974 年在 Pacific Grove 演示可用原型。【WikiKildall】【BW04】 | ★☆ |
| 1975 | 微软（Micro-Soft）成立于 Albuquerque，主营 BASIC 等语言。1978-12 迁回 Bellevue。 | ☆ |
| 1976 | Kildall 与 Dorothy McEwen 创办 Digital Research（初名 Intergalactic Digital Research，因「Digital Research」名号已被占用；Dorothy 负责商务）。⚠ DRI 条目记 1974 年创立，自传明写 1976 年运营，取 1976。【KildallMemoir】【WikiDRI】 | ★☆ |
| 1978 | DRI 月销售达 $100,000、税前利润率约 57%，迁入 Pacific Grove 维多利亚式小楼。【KildallMemoir】 | ★ |
| 1978-06 | Paterson 华盛顿大学 CS 毕业前夕，被 Rod Brock 以日薪 $50 雇来修 S-100 内存板，旋即转正。【Softalk83】 | ★ |
| 1978-07 | Paterson 提议为 SCP 开发 8086 S-100 板卡获准；1979-01 设计完成，1979-05 原型跑通——比 IBM PC 早约两年。【Softalk83】 | ★ |
| 1979-05 末 | Paterson 携原型机到微软，与 Bob O'Rear 一周内把 Standalone Disk BASIC-86 移植上 8086。【Softalk83】 | ★ |
| 1979-06 | 纽约 NCC：SCP 以微软与 Lifeboat 客卿身份展出 BASIC-86——当时 8086 唯一的软件。【Softalk83】 | ★ |
| 1979 年间 | ⚠ **Lowe 桥段**：Boca Raton 实验室主任 William Lowe 向公司管理委员会（CMC）提出进入微机市场（一说含演示 Apple II；一说建议直接收购 Atari）。IBM 传统新品周期 4–5 年，Lowe 承诺「独立小组、放弃 IBM 传统方法，一年出设计、30 天出原型」。该对白的戏剧化版本源出《Blue Magic》与《Fire in the Valley》，逐字对白不可考。【WikiIBMPc】【WikiLowe】【CNET13】【BlueMagic88】【FireValley84/00】 | ☆△ |
| 1979-11 | SCP 8086 板卡出货（Paterson 自称系统 1979-10 推出，⚠ 两说）；唯一可捆绑软件是微软 BASIC-86。CP/M-86 已宣布但一再延期。【Softalk83】【WikiPaterson】【Wiki86】 | ★☆ |

## 二、1980：豪赌之年

| 时间 | 事件 | 引证 |
| --- | --- | --- |
| 1980-06-11 | Steve Ballmer 加入微软（第 30 号员工）。 | ☆ |
| 1980-04 | Paterson 开始写操作系统（后名 QDOS）。自述动机：「I had always wanted to write my own operating system. I've always hated CP/M.」CP/M-86 若及时上市，此项目即会放弃。【Softalk83】【Drivel】 | ★ |
| 1980-07 | **Lowe 向 CMC 正式提案**（「因为我们在 IBM 的文化里做不成这件事」）；同期 Atari 向董事长 Frank Cary 提议代工 PC，Cary 转交 Lowe，Lowe 附上「干脆买下 Atari」备选，被评「我们听过最蠢的主意」，委员会限其一个月内交自建方案。⚠ 批准时间各源：7 月提案 → 8 月原型获批 → 8-21 正式放行（Project Chess 定名）；扩编至 150 人，一天 500 余名员工请缨。【WikiLowe】【CNET13】【DA1】【DA2】 | ☆ |
| 1980-07-21 | **Jack Sams 首次致电盖茨**，称次日想「friendly chat」，叮嘱「别太激动，别以为有什么大事要发生」。次日到访。【DA1】【PCMag21】 | ☆ |
| 1980-07 | QDOS 0.10（约半成品）完成。【Softalk83】 | ★ |
| 1980-08-21 | 项目绿灯后 Sams 再访微软，先签 NDA；Sams 因微软的 Z-80 SoftCard 误以为微软拥有 CP/M，**盖茨当场澄清 CP/M 属 DRI，并当面致电 Kildall 引荐**：「very important customers, so treat them right」。Sams：「我们其实只想跟一个人打交道。」【DA2】 | ☆ |
| 1980-08-22 前后 | ⚠ **IBM 代表到访 Pacific Grove 的 DRI**。通行叙事：当日 Gary 不在、Dorothy 征询律师 Gerry Davis 后拒签 IBM 单方面 NDA、谈判破裂。【WikiCPM】【PBS96】 **Kildall 自传异说**：他上午驾机去 Oakland 送文件（既定商务行程），**下午回场参加会谈，NDA 已签，达成握手意向**；事后多次致电 Sams 未获回音。详见 [争议#1](../04-谜团与争议/争议1_Kildall是否错过会面.md)。【Evans04转引】【BW04】 | ★☆ |
| 1980-08 末 | QDOS 0.11 出货。【Softalk83】 | ★ |
| 1980-09-25 ⚠ | Manes & Andrews 记微软与 SCP 已有早期协议：$10,000 取得向最终用户分发之权，OEM 转授每家 $10,000（含源码 $15,000）。【Manes93转引】 | ☆ |
| 1980-09-30 | **盖茨、鲍尔默、Bob O'Rear 飞抵佛罗里达向 IBM 做最终提案**：操作系统 + BASIC/COBOL/FORTRAN/Pascal 四种语言 + 启动软件。⚠ 注意：此为提案日，**不是签约日**。【DA3】 | ☆ |
| 1980 年秋 | 微软转向 SCP 购买 86-DOS。Allen 主动致电 Brock：「I called Rod Brock… to work out a licensing agreement… total of $25,000 for now, as we had only one customer.」协议含隐藏条款：「本协议不要求微软向 SCP 披露其客户身份」。Brock：「这听起来怪怪的，但我们同意了。」微软实际只转授一单——IBM（含源码，$25,000）。【IdeaMan11】【DA3】【Softalk83】 | ★☆ |
| 1980-11-06 | **微软与 IBM 正式签署协议**（本仓库锚点日期；CHM「历史上的今天」以该日立条）。金额各说详见 [协议要点速览](../03-关键文件/协议要点速览.md) 与 [争议#2](../04-谜团与争议/争议2_IBM到底付了多少钱.md)：艾伦回忆录分账 **$430,000**（DOS $45k + 语言 $310k + 移植测试咨询 $75k）；盖茨 PBS 口径「固定费用约 $80,000、无版税」；《The Road Ahead》p.54 **$50,000 一次性**；《数字古物志》称签约即付 **$700,000** ⚠ 与艾伦账目相抵。【CHMtdih】【PCMag21】【PBS96】【RoadAhead96转引】【DA3】 | ★☆△ |
| 1980-12 | 微软以 **$25,000** 取得 86-DOS 非独占许可（维基口径；许可文件实际落款 1981-01-06）。86-DOS 0.33（1980-11-15）为首版授权微软的版本。【Wiki86】【CHM16】 | ☆ |
| 1980 年底 | SCP 对外销售 86-DOS（OEM 与零售）；以 "Seattle DOS" 之名随自家硬件捆绑。【Softalk83】【WikiSCP】 | ★☆ |

## 三、1981：兑现

| 时间 | 事件 | 引证 |
| --- | --- | --- |
| 1981-02 至 04 | 86-DOS 0.42→0.80 快速迭代；**1981-04-28 发布 86-DOS 1.00**。【Wiki86】 | ☆ |
| 1981-05 | Paterson 加入微软专职 PC-DOS 移植；上班第一天才得知客户是 IBM：「I walk through the door and 'Hey! It's IBM.'」微软投资 86-DOS 累计 $75,000（其口径）。【Softalk83】【Micro98】 | ★ |
| 1981-07-07 | PC-DOS 1.00 **beta 内核**（2026 年公开的 Paterson 源码清单上的日期）；86-DOS 与 PC-DOS 当时是两套分开维护的代码树。【MS26】【BrokenPipe】 | ★ |
| 1981-07-21 | ⚠ Kildall 一方（携律师 Davis、Katsaros、顾问 Johnson-Laird）赴 Boca Raton 与 Estridge 对谈 PC DOS 与 CP/M 相似性问题；据 Evans 记述 IBM 当场同意同时销售 CP/M-86。盖茨据报道称 IBM「被讹上了」。【Evans04转引】 | ☆ |
| 1981-07-22/27 | **微软以 $50,000 买断 86-DOS 全部权利**（合同打字日期戳 07-22、落款 07-27；Allen 与 Brock 签署，Paterson 在座）；SCP 保留永久免版税授权。「这经常被称为世纪交易。」被收购时 SCP 仍不知客户是谁。【Wiki86】【Softalk83】【MS26】【Ars17】 | ★☆ |
| 1981-07-27 前后 | 86-DOS 更名 MS-DOS；IBM 版定名 PC DOS。IBM 在验收前提出 300 余项修改要求并亲自撰写用户手册。【Wiki86】【WikiPaterson】 | ☆ |
| 1981-08-12 | **IBM PC（5150）于纽约 Waldorf-Astoria 发布**：入门价 $1,565（16KB RAM、CGA、无软驱）；三套可选 OS——PC DOS $40、CP/M-86（同年 11 月先上 Displaywriter，PC 版 1982-04-05 才上市）$240、UCSD p-System $500+；微软 BASIC 烧入 ROM。【WikiIBMPc】【DA4】【WikiCPM86】 | ☆ |
| 1981-08-13 | PC-DOS 1.00 正式版内核日期（源码清单）。【MS26】 | ★ |
| 1981 年秋冬 | 商业结果：订单统计显示 **96.3% 的 IBM PC 配 DOS，仅 3.4% 配 CP/M-86**（PC Magazine 1983-02 调查）。Radio Shack CEO：「我不觉得它有多大意义」；Apple 整版广告「Welcome IBM. Seriously.」。【WikiCPM86】【DA4】 | ☆ |

## 四、余波（1982–1994）

| 时间 | 事件 | 引证 |
| --- | --- | --- |
| 1982 | Columbia Data Products MPC 1600——第一台洁净室逆向 BIOS 的克隆机；随后 Corona、Compaq Portable（1983-03，首年 5.3 万台/$1.11 亿营收创纪录）。一年内微软把 MS-DOS 授权给 70 余家厂商。【WikiCompat】【WikiCompaq】【WikiMSDOS】 | ☆ |
| 1982-04-01 | Paterson 突然辞职回 SCP（在微软整 11 个月）。【Softalk83】 | ★ |
| 1983 | PC DOS 随机价优势固化；IBM 年销 75 万台，月发货峰值 4 万台，销量超预期至多 800%。【WikiIBMPc】 | ☆ |
| 1984-05 | Phoenix Technologies 推出首款可对外授权的兼容 BIOS（早期授权费一次性 $290,000），克隆门槛消失。【WikiPhoenix】 | ☆ |
| 1985-08-27 | 微软去函 SCP：其 86-DOS 许可不得转让（Brock 欲售予 Tandy）。【WikiSCP】【NYT86】 | ☆ |
| 1985-11-20 | Windows 1.0 发布（MS-DOS 之上的图形外壳）。【WikiWin1】 | ☆ |
| 1986 | SCP 起诉索赔 $6,000 万；庭外和解，微软支付 **$925,000** 收回许可（⚠ 部分来源记「约 100 万」）。同年微软收购 Paterson 的 Falcon Technology（收回另一张免版税授权）。【UPI86】【WikiSCP】【Micro98】 | ★☆ |
| 1986-03-13 | 微软 IPO：发行价 $21，募资 $6,100 万，首日收 $28，市值约 $7 亿；当年营收 $1.975 亿。1980 年营收仅 $7,520,720、1981 年 $1,600 万——六年 26 倍。【WikiHistMS】 | ☆ |
| 1987-04 | OS/2 1.0 随 PS/2 发布，IBM 试图夺回 OS 控制权；1990 年前后与微软合作破裂。【WikiOS2】 | ☆ |
| 1991 | MS-DOS 每年为微软带来逾 $2 亿收入（「purchased for $50,000, was earning Microsoft more than $200 million per year by 1991」）。【Ars17】 | ☆ |
| 1994-07-11 | Gary Kildall 去世（Monterey，52 岁；死因诸说，警方曾按可能凶案调查后未起诉）。身后平反：1995 SPA 终身成就奖、2014 IEEE Milestone（DRI 旧址）、2016 CHM 公开其自传前 78 页。【WikiKildall】【CHM16】 | ☆ |
