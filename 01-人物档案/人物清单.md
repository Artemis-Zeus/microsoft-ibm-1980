# 人物清单 · 主角团

> 每人一行档案卡：**角色**（在本案中是谁）→ **关键决策**（他拍板/执行的注意事）→ **关键节点**（日期）。详细考订见各人档案文件。
> 三拨阵营一句话：**IBM 要的是速度，微软要的是产权，SCP 与 DRI 手里握着的是操作系统本身。**

## 微软侧

### 比尔·盖茨（Bill Gates）——操盘者 [档案](比尔·盖茨.md)

- **角色**：微软联合创始人，时年 24；谈判与全局决策的最终拍板人。
- **关键决策**：
  1. 1980-08-21 把 IBM 转介给 DRI——微软当时没有 OS，转介既做人情也不损失什么；
  2. 秋季转向 SCP 收购 86-DOS，而非自研（对 Sams：「你尽管去拿」）；
  3. 与 IBM 签「**许可而非卖断**」，保住向第三方授权的权利；
  4. 1981-07-27 拍板 $50,000 买断 86-DOS 全部权利。
- **关键节点**：1980-07-21/22 接待 Sams 首访 → 1980-09-30 佛州最终提案 → **1980-11-06 签约** → 1981-07-27 买断 → 1981-08-12 随 PC 发布。

### 保罗·艾伦（Paul Allen）——一线执行 [档案](保罗·艾伦.md)

- **角色**：联合创始人；SCP 两笔交易的直接操办人，IBM 项目的内部促成者。
- **关键决策**：
  1. 盯上 QDOS 并致电 Brock 启动谈判（「我们当时只有一个客户」——泄露了保密条款的用途）；
  2. 接受合同中「不得披露客户身份」条款并签字；
  3. 1981-07-27 与 Brock 签署 $50,000 买断合同。
- **关键节点**：1980 年底–1981 年初 首笔授权（$25,000）→ 1981-07-27 买断签约（Paterson 在座）。

### 史蒂夫·鲍尔默（Steve Ballmer）——运营与新贵 [档案](史蒂夫·鲍尔默.md)

- **角色**：1980-06-11 入职的第 30 号员工，管运营；本案戏份少。
- **关键决策**：无独立决策；作为三人组成员参与 9-30 佛州提案。
- **关键节点**：1980-06-11 入职 → 1980-09-30 随行提案。

## IBM 侧

### 威廉·洛（William Lowe）——立项者 [档案](威廉·洛.md)

- **角色**：Entry Systems 总监、Boca Raton 实验室主任；「IBM PC 立项之父」。
- **关键决策**：
  1. 1979–80 提出外购路线（含收购 Atari 的备选），说服管理层；
  2. 承诺「一年出设计、30 天出原型」，放弃 IBM 传统自研流程。
- **关键节点**：1979 年提议 → 1980-07 向 CMC 正式提案 → 1980-08 原型获批、项目定名 Project Chess → 随后升职，日常移交 Estridge。

### 唐·埃斯特利奇（Don Estridge）——执行者 [档案](唐·埃斯特利奇.md)

- **角色**：Project Chess 日常领军，「IBM PC 之父」；IBM 一侧全部执行的负责人。
- **关键决策**：
  1. 选 Intel 8088、开放架构、软件全部外购（含专利不执行的开放策略）；
  2. 1981-07-21 接受 Kildall 对质，同意 IBM 同时销售 CP/M-86（化解侵权威胁）。
- **关键节点**：1980-08 接掌项目 → 1981-07-21 与 Kildall 对质 → 1981-08-12 发布 IBM PC → 1985-08-02 坠机去世（48 岁）。

### 杰克·萨姆斯（Jack Sams）——采购与证人 [档案](杰克·萨姆斯.md)

- **角色**：Chess 项目软件负责人；语言与 OS 两条采购线的经手人；本案口径漂移最大的证人。
- **关键决策**：
  1. 1980-07-21/22 首访微软，谈语言、问 OS；
  2. 1980-08-21 绿灯当天二访微软，促成盖茨引荐 DRI；
  3. 秋季把 QDOS 收购的决定权交给微软（「你尽管去拿」）。
- **关键节点**：1980-07-21 致电盖茨（「别太激动」）→ 1980-08-21 二访 → 1980-08-22 前后赴 DRI（NDA 僵局）→ 1980-11-06 合同落定。

### 约翰·奥佩尔（John Opel）——高层与背景 [档案](约翰·奥佩尔.md)

- **角色**：时任 IBM 总裁（CEO 自 1981 始）；「母亲牵线说」的另一方。
- **关键决策**：无直接决策；1980 年在内部提到微软时说「那是 Mary Gates 儿子的公司」（讣告记载）。
- **关键节点**：1980 年 United Way 董事会与 Mary Gates 共事 → 1980-07 起的供应商接触期间构成「信任背书」背景。

## SCP / DRI 侧（被历史翻过来的两家）

### 蒂姆·帕特森（Tim Paterson）——系统的作者 [档案](蒂姆·帕特森.md)

- **角色**：SCP 工程师，QDOS/86-DOS 作者；全案唯一真正写出操作系统的人。
- **关键决策**：
  1. 1980-04 决定自己写 OS（CP/M-86 迟到逼出来的）；
  2. 把 API 做成与 CP/M「翻译兼容」——QDOS 能取代 CP/M 的全部秘密；
  3. 1981-05 受雇微软完成 IBM 移植；1982-04-01 辞职回 SCP。
- **关键节点**：1980-04 动工 → 1980-07 QDOS 0.10 → 1980-08 0.11 出货 → 1981-04-28 86-DOS 1.00 → 1981-05 入职微软（才知客户是 IBM）→ 1982-04-01 离职。

### 罗德·布罗克（Rod Brock）——卖家 [档案](罗德·布罗克.md)

- **角色**：SCP 所有者；把「史上最值钱操作系统」两次签字卖掉的人。
- **关键决策**：
  1. 接受含「不得过问客户身份」条款的授权合同（「怪怪的，但我们同意了」）；
  2. 1981-07-27 以 $50,000 卖断全部权利（动机：不想做软件生意、急需现金）；
  3. 1985 欲转售许可被微软阻止后起诉索赔 $6,000 万。
- **关键节点**：1980 年底首笔授权 → 1981-07-27 买断 → 1985-08 微软禁售函 → 1986 和解（$925,000）。

### 加里·基尔代尔（Gary Kildall）——失意的标准持有者 [档案](加里·基尔代尔.md)

- **角色**：DRI 创始人，CP/M 之父；IBM OS 的第一人选，本案最大的「如果」。
- **关键决策**：
  1. 拒绝 IBM 的一次性买断（$200k/$250k 两说），坚持按份版税——对既有 OEM 客户的义务；
  2. 拒签「一切发明归 IBM」式 NDA（他自传版本里 NDA 已签、有握手意向，两说并存）；
  3. 1981-07-21 亲赴 Boca Raton 对质 PC DOS 相似性，换来 IBM 同时销售 CP/M-86。
- **关键节点**：1980-07-21 接盖茨引荐电话 → 1980-08-22 前后与 IBM 会谈（细节有争议）→ 1981-07-21 对质 → 1982-04-05 CP/M-86 上市（$240 对 $40，败局已定）→ 1994-07-11 去世。

### 多萝西·麦克尤恩（Dorothy McEwen）——当天的主谈 [档案](多萝西·麦克尤恩.md)

- **角色**：基尔代尔之妻、DRI 联合创始人，分管全部商务；IBM 上门那天的 DRI 主谈人。
- **关键决策**：对 IBM 的 NDA 征询律师 Gerry Davis 后拒绝签署（通行版）；此后与 Gary 共同坚持版税路线。
- **关键节点**：1980-08-22 前后接待 IBM → 谈判破裂 → 1983 与 Gary 离婚，继续 DRI 管理层。

## 半边缘：玛丽·盖茨（Mary Gates）——信任的背书 [关联考辨](../04-谜团与争议/争议5_母亲牵线说.md)

- **角色**：盖茨之母；1980 年与 Opel 同在 United Way 全国董事会。
- **实际作用**：讣告级证据仅支持「Opel 在内部提到过一句」（「那是 Mary Gates 儿子的公司」）——买到的是信任，不是交易。
