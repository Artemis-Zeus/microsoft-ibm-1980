# 蒂姆·帕特森 Tim Paterson

> 状态：已考订（引证代号见 [`docs/来源代号表.md`](../docs/来源代号表.md)）

- **1956-06-01 生**；QDOS/86-DOS 作者，「DOS 之父」头衔的拒绝者。本案中「鸡」的实际下蛋人。
- **本案角色**：在 SCP 写出 86-DOS → 受雇微软完成 IBM PC 移植 → 亲历两笔 SCP 交易 → 1986 年诉讼与 2004–2007 诽谤案的两端当事人。

## 关键动作（按时间）

- 1978-06 — 被 Rod Brock 以日薪 $50 雇来修内存板，旋即转正；同年提议开发 8086 板卡。【Softalk83】
- 1979-05 — 原型跑通；携机赴微软协助移植 BASIC-86。【Softalk83】
- 1980-04 — 开始写 OS：「第一步，写下 CP/M-80 都做了什么。第二步，设计一个快而高效的文件系统。」目标「翻译兼容」CP/M API，但**从未见过 CP/M 源码**（「To this day, I have never seen any CP/M code.」）。【Drivel】
- 1980-07 / 08 — QDOS 0.10（7 月）→ 0.11 出货（8 月底）；自述投入「两个工月」左右。【Softalk83】【Micro98】
- 1980 年底 — 86-DOS 开始对 OEM 销售；微软是客户之一，合同规定「我们不能问他们卖给谁」。【Softalk83】【DA3】
- 1981-05 — 加入微软专职 PC 移植，「上班第一天走进门：『嘿！是 IBM！』」；IBM 提 300 余项修改要求，「IBM 想要 CP/M 风格的提示符。看得我想吐。」【Softalk83】
- 1981-07-27 — 应邀在座见证 Allen–Brock 买断签约：「So on July 27, 1981, the operating system became Microsoft's property.」【Softalk83】
- 1982-04-01 — 突然辞职回 SCP（在微软「整十一个月」）；后创办 Falcon Technology，1983–84 为微软写 MSX-DOS；1986 年微软收购 Falcon 以收回免版税授权；1986–88、1990–98 两度在微软。【Softalk83】【WikiPaterson】
- 2004–2007 — 因 Evans《They Made America》称 86-DOS 为 CP/M 的 "slapdash clone" 提诽谤诉讼，开审前被驳回（法官认定其为 limited purpose public figure、涉诉言论属受保护意见）。【WikiPaterson】

## 他的关键自述

> 「我更喜欢『原作者』这个说法。我不喜欢『发明者』这个词，因为它暗示了一种其实并不存在的创造性。」——【Micro98】

> 「没有任何迹象表明我写 DOS 时抄了任何 CP/M 代码。」——【Drivel】

> 「卖掉它是正确的决定。没有它 SCP 日子过得也不错。时机是合适的。Rod Brock 和 Paul Allen 谈判时我被邀请旁听。我觉得很荣幸。」——谈 1981 买断，【Softalk83】

## 争议言行

- 86-DOS 是否「克隆」CP/M——他坚持 API 兼容 + 代码原创；OS/2 Museum 反汇编分析支持「zero evidence of infringement」。见 [争议#4](../04-谜团与争议/争议4_QDOS是否克隆CPM.md)。
