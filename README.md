# 1980：微软与 IBM 的「惊天豪赌」史料库

> **题记**：1980 年 11 月 6 日，微软与蓝色巨人 IBM 签署的 PC 操作系统合作协议，被公认为商业史上最伟大的「惊天豪赌」与「借鸡生蛋」的典范。
> —— 本仓库的使命，就是用史料把这句话讲清楚。

## 这是什么

一个公开的**史料收集与叙事仓库**：围绕 1980 年微软-IBM PC 操作系统协议（以及作为前奏的 QDOS/86-DOS 收购、作为余波的 MS-DOS 标准化），收集一手与二手史料、整理时间线、辨析传说，最终写成一部**有据可查的故事**（见 [STORY.md](STORY.md)）。

### 方法论三原则

1. **每说一句，尽量给一个出处** —— 叙述中的关键事实，链接到 `02-史料摘录/` 中对应的著录条目；
2. **区分「史实」与「传说」** —— 广泛流传但各来源说法不一的细节，一律标注 `[待考]`，并集中列入 `04-谜团与争议/`；
3. **数字要追溯** —— $25,000、$50,000 这类著名金额，注明出自哪个来源的哪一版说法，不裸引。

## 如何收录一条史料

1. 复制 [`模板/史料著录模板.md`](模板/史料著录模板.md) 到 `02-史料摘录/`，按 `年份_来源_主题.md` 命名；
2. 按模板著录（出处、页码/章节、查见日期务必写全）；
3. 与故事直接相关的发现，回填到 [STORY.md](STORY.md) 对应章节和 `00-大事年表/`，并更新 `[待考]` 状态；

```bash
git add .                          # 暂存
git commit -m "收录：Hard Drive 第X章 关于协议金额的记载"   # 提交
git push                           # 推送到 GitHub
```
