# Git 日常使用速查

本仓库的日常使用只涉及最基础的 Git 操作，记住下面三步就够了。

## 核心概念

```
工作区（你正在编辑的文件）
   │  git add      ← 「暂存」：把改动放进待存清单
   ▼
暂存区（这次要保存的内容）
   │  git commit   ← 「提交」：打一个版本快照，附说明
   ▼
本地仓库（完整的历史记录）
   │  git push     ← 「推送」：备份到 GitHub
   ▼
GitHub（云端，可回溯任意历史版本）
```

## 日常三步

```bash
git add .                         # 1. 暂存全部改动（也可指定单个文件）
git commit -m "新增：某某著录"      # 2. 提交，说明写清楚做了什么
git push                          # 3. 推送到 GitHub
```

## 常用查看命令

```bash
git status        # 看当前哪些文件改了、哪些已暂存
git log --oneline # 看提交历史（一行一条）
git diff          # 看尚未暂存的具体改动
```

## 后悔药

```bash
git restore --staged 文件名   # 取消暂存（文件内容不变）
git restore 文件名            # 丢弃未提交的修改（慎用，改不回来）
git checkout 提交号 -- 文件名  # 把某文件恢复到历史某版本
git revert 提交号             # 生成一条「反向提交」撤销某次提交，安全
```

## 良好习惯

- **小步提交**：一次提交只做一件事，说明里写「新增/修订/勘误 + 对象」；
- **推送前看一眼** `git status`，避免把临时文件（可用 `.gitignore` 屏蔽）带进去；
- 大图片入仓库前先看 `02`、`03` 目录说明里的体积建议。
